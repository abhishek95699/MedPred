# Design Guidelines

## Palette
- Background: #FFFFFF (white sections)
- Section Alt: #F7F6FB (pale lavender-gray)
- Primary: #4F46E5 (indigo)
- Primary Foreground: #FFFFFF
- Text: #1F2033 (charcoal)
- Muted Text: #6B6B80
- Border: #E4E2F0
- Card: #FFFFFF
- Ring: #4F46E5

## Typography
- Geometric-humanist sans: Inter + Geist
- No serif anywhere
- Display headings: Inter 700–800, tight tracking
- Body: Inter 400–500
- Labels/mono: Geist Mono for data values

## Shape
- Border radius: 12px standard, 9999px for pills
- Buttons: pill-shaped (rounded-full)
- Cards: rounded-xl (12px)
- Hero screenshot: rounded-2xl with soft diffuse box-shadow

## Composition
- Centered layout, max-w-6xl container
- Hero: centered headline + subhead + CTA pills, floating rounded UI screenshot below
- Logo row: grayscale medical dataset/org logos
- Features: three-up grid of rounded cards
- Predictions: tabbed interface with form + result card

## Mood
- Clean clinical intelligence; indigo signals trust and precision
- Alternating #F7F6FB / #FFFFFF sections create rhythm
- Soft diffuse shadows (no hard drop shadows)
- Never: flush-left Swiss composition, hairlines, serif, vermilion, editorial photography
